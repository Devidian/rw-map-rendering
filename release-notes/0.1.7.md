# Map renderer 0.1.7

This release supports optional map source retention in OZ Admin Utils 0.15.2. Set `mapAckToken` only for a server whose Admin Utils plugin has the matching `mapRendererAckToken`. After writing a source page to its local cache and rendering tiles, the renderer acknowledges those chunk versions. Servers without a token continue to render normally.

One renderer process can serve multiple game servers. Each server keeps its own ID, cursor, cache and tiles. With acknowledgement enabled, a full sync preserves older cached chunks and tiles that Admin Utils has already cleaned up.

Keep the renderer's tile and source-cache volume persistent and backed up. Complete a full sync before enabling Admin Utils cleanup; use one authoritative renderer per world. If renderer storage is lost after source cleanup, removed terrain must be captured again by visiting it in game.
