# Map renderer 0.1.6-rc.1

This release candidate adds `PUBLISH_MODE=archive` for both RSYNC and SFTP. It groups each tile column into a ZIP archive and publishes metadata JSON at the existing URLs. The included Apache rewrite and PHP reader serve terrain and satellite PNGs through the original tile URL templates. The default `raw` mode remains available.

For SFTP, changed archives are uploaded to a staging directory and moved into place. An initial scan builds archives for existing maps; idle and periodic reconciliation can be enabled separately. Existing raw tiles are not deleted by the renderer.

The first Development deployment uses the STRATO webspace at `https://rw-tileserver.omega-zirkel.de/`. Player-facing speed and concurrent request behavior require acceptance testing after the initial sync.
