# Map renderer 0.1.5-rc.3

This release candidate polls the optional Admin Utils satellite routes, stores source PNGs separately from terrain data, builds a satellite tile pyramid, and publishes `satelliteTileUrl` only after tiles exist. Terrain rendering and existing map URLs remain available.

Deploy before Manager backend 0.8.0-rc.2 and frontend 1.8.0-rc.2. The source server must run an Admin Utils build with `sat-changes` and `sat-tile` routes; servers without those routes continue with terrain tiles. Existing renderer state and source tiles are retained on rollback to 0.1.5-rc.2.

Validation: TypeScript build, 12 test suites and 33 tests including the CI coverage gate. A real Development PNG was confirmed through the native tile route; production satellite tile alignment remains a visual acceptance item.
