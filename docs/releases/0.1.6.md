# Map renderer 0.1.6

This stable release adds archive publication for RSYNC and SFTP. Set `PUBLISH_MODE=archive` to group each tile column into a ZIP while keeping terrain, satellite, and metadata URLs unchanged. The included Apache rewrite and PHP reader serve individual PNG requests from those archives. The default `raw` publication mode remains available.

SFTP uploads changed archives through a staging directory and promotes them after transfer. Initial seeding, optional idle sync, and periodic reconciliation support existing maps. Archive mode does not remove old raw tiles automatically.

The release candidate completed its initial sync on the STRATO webspace for three map servers. Terrain and satellite responses were byte-identical to the source tiles. The user accepted Development performance, including the currently largest map, "Eine neue Welt". Shared-hosting behavior under higher concurrent load remains to be observed.
